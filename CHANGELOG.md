# Changelog

## [1.0.0]

- Add registration, player profiles, administrator bootstrap, password resets, tournament-specific organizers, and audit history.
- Record and arbitrate singles and doubles results with chronological Elo replay.
- Run round-robin, rotating-partner doubles, knockout, and group-to-playoff tournaments with automatic start and completion.
- Publish player comparisons, galleries, standings, and match history in an English and Russian progressive web app.
- Package separate FastAPI and React processes and add reviewed database migrations, recovery tooling, and GitHub workflow definitions.
